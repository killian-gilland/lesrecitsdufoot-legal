Privacy Policy

Les Récits du Foot Studio · Last updated: 2026-10-29

Les Récits du Foot Studio is a personal tool used by a single person, the owner of the TikTok account @lesrecitsdufoot, to publish videos they produce to their own TikTok account. It is not offered to the public and has no other users.

Data we access

  • Basic TikTok profile information (open ID, username, display name, avatar) of the owner's account, through the user.info.basic scope, to confirm which account videos are published to.
  • Permission to publish videos to the owner's account, through the video.publish scope.

We do not access followers, messages, likes, comments, viewing history or any data about other TikTok users.

How data is used and stored

  • Access tokens are stored only on the owner's own computer, in a local file that is never shared or uploaded anywhere.
  • Data is used solely to publish the owner's videos to the owner's account.
  • No data is sold, rented, shared with third parties or used for advertising.

Deleting data

Access can be revoked at any time from the TikTok app (Settings and privacy → Security → Apps and services). Deleting the local token file removes all stored data.

Politique de confidentialité

Les Récits du Foot Studio est un outil personnel, utilisé par une seule personne, propriétaire du compte TikTok @lesrecitsdufoot, pour publier ses propres vidéos sur son propre compte. Il n'est pas proposé au public et n'a aucun autre utilisateur.

Données utilisées : les informations de base du profil TikTok du propriétaire (identifiant, nom d'utilisateur, nom affiché, photo) et l'autorisation de publier des vidéos sur ce compte. Aucune donnée sur d'autres utilisateurs n'est consultée.

Stockage : les jetons d'accès restent sur l'ordinateur du propriétaire, dans un fichier local jamais partagé. Aucune donnée n'est vendue, partagée ou utilisée à des fins publicitaires.

Suppression : l'accès se révoque à tout moment dans l'application TikTok (Paramètres et confidentialité → Sécurité → Applications et services) ; supprimer le fichier local efface toutes les données stockées.
